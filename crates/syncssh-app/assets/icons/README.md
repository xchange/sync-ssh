SyncSSH application icon, second design from the “生成 macOS 应用图标” review.

`SyncSSH-source.png` preserves the selected generated image. `SyncSSH.png` is
the 1024 px source for packaging; `.icns` contains macOS 16–1024 px variants and
`.ico` contains Windows 16, 24, 32, 48, 64, 128 and 256 px variants. Alpha is
preserved. These assets are embedded or copied by the platform build scripts.
